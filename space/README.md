# Embeddings Over Time Explorer

Interactive explorer for **yearly word2vec embeddings** trained on [FineWeb](https://huggingface.co/datasets/HuggingFaceFW/fineweb). Track how word meaning shifts across years (2005–2022).

## Features

- **Nearest neighbors** — cosine similarity in a chosen year
- **Semantic evolution** — similarity between word groups over time
- **Embedding projection** — 1D/2D semantic axes
- **Word analogies** — vector arithmetic (e.g. king − man + woman)

## Artifacts

- **Models:** [adameubanks/YearlyWord2Vec](https://huggingface.co/adameubanks/YearlyWord2Vec)
- **Dataset:** [adameubanks/filtered_articles_by_year](https://huggingface.co/datasets/adameubanks/filtered_articles_by_year)
